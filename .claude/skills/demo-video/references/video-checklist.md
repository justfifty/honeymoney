# Demo-video checklist + mistakes to avoid

Pre-ship gate for the **demo-video** skill. Rules + sources in `video-production.md` /
`video-structure.md`.

## Pre-production
- [ ] Script ≤ ~430 words (150 wpm × ~2.9 min), one idea per sentence, written for the ear
- [ ] Two-column storyboard: each VO line ↔ its exact on-screen action
- [ ] Demo data pre-staged in the live app; a shared goal *about to slip* so the Honey insight lands
- [ ] Telegram screenshot pre-staged for a fast on-camera parse
- [ ] Clean desktop; window fixed to a consistent size + readable zoom
- [ ] Hook lands in ≤8s, real visual in ≤5s (no logo intro, no "welcome")
- [ ] Each beat mapped to a T3 criterion (Technical/Commercial/Relevance/Scalability/ESG)

## Recording
- [ ] 1080p, 100% scale, 30 fps
- [ ] Silent clean B-roll first, in 5–10 min segments; reset on any mistake
- [ ] VO recorded separately: quiet room, decent mic, peaks -12 to -6 dB
- [ ] No redundant clicks / menu hovering / dead air
- [ ] Only real screens — nothing faked or mocked up

## Edit
- [ ] Cut all dead air / thinking pauses; speed-ramp loading to 1.5–2×
- [ ] Zoom + one consistent annotation style on key actions; cursor smoothing on
- [ ] Music 15–20 dB under VO, ducked; master -15 to -13 LUFS, true peak ≤ -2 dBTP
- [ ] Captions edited (not raw auto), ≤2 lines, ≤~42 chars/line, white-on-black, synced, 120–160 wpm
- [ ] Knowledge-graph moment: quick, legible, narrated as user benefit (not schema)
- [ ] End card: logo + one-line pitch + honeymoney.app, high contrast

## Publish
- [ ] Total runtime **under 3:00** (verify) — target 2:15–2:50
- [ ] Export MP4 1080p; **confirm format against official MAIC T3 rules**
- [ ] Host YouTube Unlisted (or per required method); descriptive title + keyword description
- [ ] Test the link in an incognito window; test captions on mobile
- [ ] **Replace the placeholder link in `docs/REGISTRATION.md` §7** with the final URL

## Mistakes that lose viewers/judges
- Over the 3:00 cap · slow/generic intro (logo, "hi my name is")
- Feature-dumping with no narrative · one workflow beats a feature tour
- Poor audio (echoey, hot/quiet, music burying VO)
- No captions (loses >50% muted viewers + fails accessibility)
- Faking/exaggerating a feature or passing a mockup as live — fatal with technical judges
- Burying what you actually do / burying a strong metric
- Dead air, thinking pauses, redundant clicks
- Tiny unreadable UI · jargon-heavy graph explanation
- No single clear takeaway / weak CTA (fade to nothing)
